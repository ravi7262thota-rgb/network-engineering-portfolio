# Project 02 – IPv4 Addressing and Subnetting

## 1. Project Objective
Understand IPv4 addressing, subnet masks, CIDR notation and subnet calculations.

## 2. IPv4 Addressing
IPv4 is a 32-bit logical addressing system divided into four octets.

Example:
192.168.1.10

## 3. Subnetting Example

| Parameter | Value |
|---|---|
| IP Address | 192.168.1.10 |
| Subnet Mask | 255.255.255.0 |
| CIDR | /24 |
| Network Address | 192.168.1.0 |
| Broadcast Address | 192.168.1.255 |
| First Usable IP | 192.168.1.1 |
| Last Usable IP | 192.168.1.254 |
| Usable Hosts | 254 |

## 4. Important Networking Concepts

- IP Address

- Network Address
