# Network Fundamentals – Practical Lab

## Project Objective
Understand basic networking concepts and perform practical network troubleshooting using Windows CMD.

## Topics Covered
- OSI Model
- TCP/IP Model
- IPv4 Addressing
- Default Gateway
- DNS
- DHCP
- MAC Address

## Practical Exercises

### Exercise 1: IP Configuration
```cmd
ipconfig /all
```
Result: Successfully identified network configuration.

### Exercise 2: Network Connectivity
```cmd
ping 8.8.8.8
```
Result: Successful.

### Exercise 3: DNS Resolution
```cmd
nslookup google.com
```
Result: Successful.

### Exercise 4: Network Route Tracing
```cmd
tracert google.com
```
Result: Successful.
